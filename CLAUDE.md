# TrustLens Agent (RealHack 2026)

This repository hosts the TrustLens Agent proposal for RealHack 2026 — a proactive decision-intelligence layer over RealPage Revenue Management that aims to make pricing recommendations explainable, testable, and controllable through agentic workflows, rule-based validation, and LLM-generated decision narratives. See [README.md](README.md) for the full proposal.

## Conventions

No application code is committed, so there is nothing to infer from real source files yet. The only conventions in force today are inherited from the gh-aw scaffolding:

- Markdown is the source-of-truth format for workflows and agent definitions (`.github/workflows/*.md`, `.github/agents/*.agent.md`). `.lock.yml` files are **generated** by `gh aw compile` and must never be hand-edited.
- Two-space indentation in JSON config (`.github/mcp.json`, `.vscode/settings.json`).
- Line-ending policy is git-default; `.gitattributes` only governs lock-file merge behavior.

When application code lands, an agent updating this file should re-infer conventions from 2–3 representative source files (naming, imports, error handling, test style) and replace this section.

## Off-limits to agents

Agents must NOT modify the following without an explicit user instruction:

- `.github/workflows/*.lock.yml` — generated by `gh aw compile`; edit the source `.md` and recompile instead.
- `.github/workflows/copilot-setup-steps.yml` — pins the gh-aw CLI version; bump only via the gh-aw upgrade prompt.
- `.github/agents/agentic-workflows.agent.md` — vendored from gh-aw; replace via `gh aw init` or the upgrade flow, not by hand.
- `.github/mcp.json` — MCP server registration; managed by `gh aw`.
- `.gitattributes` — generated-file rules for gh-aw.
- `.vscode/`, `.git/` — local environment / VCS internals, not project source.
- Any future `.env`, `*.env.local`, `secrets.*`, `*.pem`, `*.key`, or credential files (none exist yet; the rule applies preemptively).

If a task appears to require touching one of these, stop and ask the user first.
